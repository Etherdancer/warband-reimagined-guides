# Warband Reimagined - guides

Guides for the Steam Workshop mod **Warband Reimagined** by Etherdancer.

- [Full feature list](FEATURES.md)
- [Changelog](CHANGELOG.md) - what changed in each build
- [Testing guide](TESTING.md) - please read if you want to help test

**New game required. Not play-tested yet: feedback is very welcome.**

**Light on any PC.** The mod uses Native's own models, textures, scenes, sounds and music; the only new art is the title logo. It runs on older and weaker machines as well as Native does.

Feedback and bug reports: use the Comments and Discussions tabs of the mod's Steam Workshop page. Every report helps, including "it works fine".
