# Warband Reimagined - guides

Guides for the Steam Workshop mod **Warband Reimagined** by Etherdancer. Current version: **11.7** (the 11 "Free Road" line).

- [Player's roadmap](ROADMAP.md) - a route through the game: what to do first, where the big stories begin and what each needs
- [Full feature list](FEATURES.md) - everything in the mod, grouped by theme
- [Changelog](CHANGELOG.md) - what changed in each version
- [Testing guide](TESTING.md) - what to check and how to report it

**New game required.** Saves from versions before 11 do not work with version 11. Saves from 11.3 and later keep working.

**Not play-tested yet.** The mod is built and checked by tools, but this version has not been played through. Feedback is very welcome.

**Light on any PC.** The mod uses Native's own models, textures, scenes, sounds and music. The only new picture is the title logo. It runs on older and weaker machines as well as Native does.

## Install

1. Subscribe to the mod on the Steam Workshop.
2. Start Warband and pick **Warband Reimagined** in the launcher.
3. Start a **new game**.

## Feedback

Use the Comments and Discussions tabs of the mod's Steam Workshop page. Every report helps, including "it works fine".
